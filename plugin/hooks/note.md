# agent-worktree

Task worktrees are made with `agent-worktree`. To work on a task in its own checkout, run `agent-worktree create <name>` in the repository and work in the path it prints; EnterWorktree and a subagent's `isolation: "worktree"` go through the same tool. Never use `git worktree add` or `git worktree remove`. When the task's work is committed, run `agent-worktree remove <name>`. A worktree entered with EnterWorktree is left with ExitWorktree `action: "keep"`, then removed with `agent-worktree remove <name>`; Claude Code cannot verify a worktree its hook created, so its own remove refuses. A refusal names the act that resolves it; do it rather than working around the tool.
